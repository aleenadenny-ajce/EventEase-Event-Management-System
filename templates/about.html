EventEase Architecture & System Overview

A comprehensive, modular web application engineered to demonstrate full-stack cloud computing principles: virtualization, Docker containerization, Kubernetes orchestration, and AWS serverless computing.

Module 1 & 2: Virtualization & VM Automation
Hypervisor Layer

Investigates Type-1 (bare-metal) vs. Type-2 (hosted) hypervisors. Explains how applications historically ran on physical servers, transitioned to hardware-virtualized environments (VirtualBox/KVM/QEMU), and examines CPU, RAM, disk allocation, snapshots, and automation scripts.

  • VirtualBox VM creation & snapshot workflows for Windows
  • KVM / QEMU and virsh CLI commands for Linux systems
  • Resource allocation and troubleshooting virtualization bottlenecks
Module 3: Docker Containerization
Container Runtime

Packages EventEase and its Python dependencies into an immutable, portable Docker container image with non-root security, integrated health probes, and persistent volume mounting.

  • Multi-layer Dockerfile using official Python slim base
  • Docker Compose for single-command deployment with volume persistence
  • Built-in Docker HEALTHCHECK utilizing the /health endpoint
Module 4: Kubernetes Orchestration
Cluster Orchestration

Defines declarative Kubernetes YAML manifests for deploying EventEase onto Minikube or cloud Kubernetes clusters (EKS/GKE/AKS), with automated healing, rolling updates, and scaling.

  • Dedicated Namespace (eventease), ConfigMap, and Secret
  • Readiness & Liveness probes targeting /health
  • NodePort Service for local access and scaling demonstration
Module 5: AWS Serverless Computing
FaaS & Event Driven

Implements an independent AWS Lambda microservice that ingests event registration notifications, validates payload schema, and generates digital confirmation summaries.

  • AWS Lambda Python handler with structured JSON responses
  • AWS SAM (Serverless Application Model) template.yaml
  • Local testing script without requiring active cloud credentials
